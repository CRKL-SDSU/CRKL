Instructions

Space exploration catalog: searching, browsing, and the API console

CRKL-Space:

  • Explore (/explore): the main catalog for searching and browsing.

What's in the catalog

ResourceWhat it describesExample
MissionsA space mission, its target body, and its statusMercury Magnetospheric Boundary Mapper
AgenciesAn organization taking part in missionsNASA, ESA, JAXA, SpaceX, ISRO
SpacecraftA vehicle or instrument platformOrion Deep Space Variant
LaunchesA launch event with its date, window, and statusFalcon Heavy Interplanetary

Missions are the center of the catalog. Each mission can be linked to:

  • several agencies, each with a role such as Primary or Contributor
  • several spacecraft
  • several launches

Agencies, spacecraft, and launches are connected to each other through missions. For example, to find the spacecraft an agency has used, open the agency, open one of its missions, then look at that mission's spacecraft.

Explore: searching the catalog

Open http://localhost:3000/explore.

Choose what to search

Under the search box, select Search in: Missions, Agencies, Spacecraft, or Launches. The results always show records of this type. Switching type clears the current results.

Type a keyword and press Search

  • Search is case-insensitive and matches anywhere inside a field. orbit finds Martian Phobos Orbital Insertion.
  • Multi-word input is treated as one phrase, not separate words. solar observatory matches Aditya-L1 Solar Observatory but not a record that only contains "solar" and "observatory" far apart.
  • Leave the box empty and press Search to list all records of the selected type.

Fields searched for each type:

Searching inMatches on
Missionsname, description, target body, status, source provider
Agenciesname, abbreviation, country code, source provider
Spacecraftname, spacecraft type, source provider
Launchesname, status, source provider

Include related records (on by default)

When Include related records is checked, a record also matches if a linked record matches your keyword:

Searching inAlso matches when…
Missionsa linked agency, spacecraft, or launch matches
Agencies / Spacecraft / Launchesa linked mission matches (name, description, target body, status)

Examples:

Search inKeywordRelated onRelated off
MissionsNASAEvery mission NASA takes part inOnly missions with "NASA" in their own text
SpacecraftMoonSpacecraft that flew on Moon missionsOnly spacecraft with "Moon" in their name/type
LaunchesMarsLaunches carrying Mars missionsOnly launches with "Mars" in their name

Uncheck the box for exact, single-table matching.

Read the results

The heading shows how many results are displayed and how many records matched in total. Each result card shows:

  • the record type and its #ID
  • the record name
  • a few key fields

Note: Explore displays up to 100 results per search. If more records match, use a more specific keyword.

Explore: viewing details

Click any result card to open its detail panel.

The panel shows:

  1. All fields of the record (dates, status, …). Empty values are shown as —.
  2. Related records, grouped by type. A mission shows its agencies (including each agency's role), spacecraft, and launches. An agency, spacecraft, or launch shows its missions.

Following links

Click any related record to open it in the same panel. This lets you walk through the catalog, e.g.:

NASA → Lunar South Pole Habitation Scout → Orion Deep Space Variant → every mission Orion flew on

Panel controls

ControlAction
← BackReturn to the previous record you viewed
Forward →Go forward again after using Back
×Close the panel
Click outside the panelClose the panel
Esc keyClose the panel

Back and Forward work like browser history. If you go back and then open a different record, the forward history is discarded. Closing the panel clears the history.
