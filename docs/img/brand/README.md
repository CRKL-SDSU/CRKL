# CRKL-Space logo

| File | Use |
| --- | --- |
| `crkl-space-logo.svg` | Mark + wordmark. Switches between light and dark colors with the viewer's OS setting. |
| `crkl-space-logo-light.svg` | Mark + wordmark for light backgrounds (fixed colors, for slides and documents). |
| `crkl-space-logo-dark.svg` | Mark + wordmark for dark backgrounds (fixed colors). |
| `crkl-space-wordmark.svg` | "CRKL /SPACE" only, light/dark by OS setting. |
| `crkl-space-mark.svg` | The targeting mark only (the site icon is `frontend/app/icon.svg`). |

- "CRKL" is Barlow Semi Condensed SemiBold (SIL Open Font License 1.1), converted to outlines, so no font is needed to display the files.
- "SPACE" is drawn with straight 1-unit strokes on a 12 x 20 grid, like a pen plotter. The slash uses the accent color.
- Colors match the site theme: text `#131a26` / `#eef2f8`, muted `#5a6577` / `#8793a8`, accent `#a8541a` / `#f1a35b` (light / dark).
- The live site draws the same logo from `frontend/app/brand.tsx`; keep the two in sync when changing it.
